# BUILT// ONGRID

Creative digital studio landing site built with Next.js for Vercel.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Deploy

Push this folder to GitHub and import the repository into Vercel, or run `vercel` from the project directory.

## Before launch

- Replace `hello@builtongrid.com` with the final business email.
- Confirm the public phone number.
- Replace the spec project cards with real work when available.
- Add social links once Instagram exists.
- Consider registering the final domain after checking availability/trademark conflicts.
